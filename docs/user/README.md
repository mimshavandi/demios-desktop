# User guide

How to use Demios Desktop. This guide covers only what the app does today. Demios Desktop is pre-release (version 0.1.0), so expect changes.

1. [Getting started](getting-started.md): build the app and send your first message
2. [Adding a model](models.md): run a model on this device, or use your own API key
3. [Chats](chats.md): send, stop, retry, copy and delete
4. [Projects](projects.md): chats, files and instructions grouped together
5. [Skills](skills.md): change how the assistant works in a chat
6. [Artifacts](artifacts.md): pages, apps, diagrams and documents the model makes
7. [Tools and approvals](tools-and-approvals.md): how tool calls ask for your OK
8. [Your Demios Node](node.md): sync your chats and projects through a machine you own
9. [Privacy and your data](privacy.md): where your data goes, and how to delete it
10. [Reporting a problem](reporting-a-problem.md): report a bug or a bad answer
11. [Keyboard shortcuts](keyboard-shortcuts.md)
12. [Troubleshooting](troubleshooting.md)

Using the `dn` command-line tool instead? See [The dn command-line tool](dn-cli.md).
