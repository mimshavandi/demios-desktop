# User guide

How to use Demios Desktop. This guide covers only what the app does today. Demios Desktop is pre-release (version 0.1.0), so expect changes.

1. [Getting started](getting-started.md): build the app and send your first message
2. [Adding a model](models.md): run a model on this device, or use your own API key
3. [Chats](chats.md): send, stop, retry, copy and delete
4. [Tools and approvals](tools-and-approvals.md): how tool calls ask for your OK
5. [Privacy and your data](privacy.md): where your data goes, and how to delete it
6. [Reporting a problem](reporting-a-problem.md): report a bug or a bad answer
7. [Keyboard shortcuts](keyboard-shortcuts.md)
8. [Troubleshooting](troubleshooting.md)

Using the `dn` command-line tool instead? See [The dn command-line tool](dn-cli.md).
