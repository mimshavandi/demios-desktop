# Chats

## Send a message

Type in the message box at the bottom and press **Enter**. For a new line, press **Shift+Enter**.

The answer appears as the model writes it. Answers can contain formatting, lists, tables and code blocks with highlighted code.

The name of the model that wrote an answer appears under it once it's finished, and screen readers announce each answer as "AI answer". The line under the message box is a reminder: answers come from the AI model you chose and can be wrong, so check important facts.

## Stop, retry and copy

- **Stop an answer:** select the stop button where the send button was, or press ⌘. (Ctrl+. on Windows and Linux). The answer keeps what was written so far and shows "Stopped".
- **Retry:** select **Retry** under the last answer to get a new one. It also appears when an answer was stopped or failed.
- **Copy an answer:** select the copy button under it. ⌘⇧C (Ctrl+Shift+C) copies the last answer.

If an answer stops early, a note says why: it hit the length limit, or it reached the maximum number of tool steps.

## Your chats

Chats are listed in the sidebar under **Recent**, the most recently used first, and stay on your computer between launches. A chat is named after the start of its first message.

- **New chat:** select **New chat** in the sidebar or press ⌘N (Ctrl+N).
- **Open a chat:** select it in the sidebar.
- **Delete a chat:** point at it in the sidebar and select the delete button. The chat goes at once, and a message lets you **Undo** for 10 seconds. After that it is removed for good the next time the app starts.
- **Hide or show the sidebar:** select the sidebar button at the top left, or press ⌘\ (Ctrl+\).

## Artifacts pane

The button at the top right shows or hides the artifacts pane. Artifacts (documents, code and small apps a model makes) aren't in the app yet, so the pane is empty for now.
