# Keyboard shortcuts

On Windows and Linux, use Ctrl where macOS uses ⌘.

| Action | macOS | Windows and Linux |
|---|---|---|
| New chat | ⌘N | Ctrl+N |
| Open Settings | ⌘, | Ctrl+, |
| Stop the answer | ⌘. | Ctrl+. |
| Copy the last answer | ⌘⇧C | Ctrl+Shift+C |
| Show or hide the sidebar | ⌘\ | Ctrl+\ |
| Send the message | Enter | Enter |
| New line in the message | Shift+Enter | Shift+Enter |

## On an approval card

| Action | macOS | Windows and Linux |
|---|---|---|
| Allow once | ⌘↵ | Ctrl+Enter |
| Deny | Esc | Esc |

The card ignores keys pressed in the first half second after it appears, so a key meant for something else can't approve it by accident.

## In the artifact pane

Press Esc to close the pane, also while the artifact has focus. From inside an artifact, the shortcuts for a new chat, Settings and the sidebar still work; to stop an answer or copy the last one, click into the chat first. See [Artifacts](artifacts.md).

## In Settings

- The section list on the left (**General**, **Models**, **Tools**, **Skills**): Up and Down move to the previous or next section and open it; Home and End go to the first and last. On a narrow window the list is a drop-down instead.
- The tabs on **Models** (**On this device**, **Providers**): Left and Right move between them; Home and End go to the first and last.
- Settings opens on the page you had open last.
