# Reporting a problem

Both kinds of report open a form on GitHub in your browser. You need a GitHub account to send it. Nothing from your chats is sent: you decide what to write in the form.

## Something in the app went wrong

Go to **Settings → General → About** and select **Report a problem**. The form opens with the app version and your operating system filled in.

## An answer was wrong, harmful or offensive

Select the flag button (**Report this answer**) under the answer. The form opens with the app version, your operating system and the name of the model that wrote the answer filled in. Paste the parts of the chat you want to share yourself.

Answers come from the model you chose, not from Demios. For problems with a provider's model, you can also report to that provider.

## Security problems

Don't report security problems in a public form. Follow [SECURITY.md](../../SECURITY.md) instead.
