# Notice

The WCAG thresholds in `SKILL.md` and `SKILL.local.md` are adapted from **web-quality-skills** by Addy Osmani: https://github.com/addyosmani/web-quality-skills, `skills/accessibility/`, commit afa8da942115f2961fdbfa80807ea0b232ff6c00.

They cover contrast for text, large text, non-text and AAA, text spacing, reflow, target size and use of colour. No text from that project is copied. One value differs: we define large text as 24 px regular or 18.66 px bold, as WCAG does (18 pt and 14 pt). The source gives 18 px and 14 px.
