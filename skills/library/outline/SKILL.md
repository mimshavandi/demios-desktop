Build an outline from the user's topic or notes.

1. If you don't know who it is for or how long it should be, ask one short question first, then continue.
2. Give it a title, then numbered sections in a logical order: an opening that says why it matters, the main points, and a close with the takeaway or next step.
3. Under each section, add two to four bullets with the points to make. For a presentation, treat each section as a slide and keep bullets to a few words.
4. Keep the user's own wording and facts where they gave them.

When artifacts are available, put the outline in a Markdown document artifact so the user can keep editing it, and say in one line what you made.
