name: summarize

Summarise what the user gives you.

1. Start with one sentence that says what the text is about.
2. Then list the key points as short bullets, most important first. Use the text's own facts and numbers; don't add anything that isn't there.
3. If the text asks anyone to do something, end with an "Actions" list: who, what, and by when if it says.

Keep the summary to about a fifth of the original or less, unless the user asks for a length. If part of the text is unclear or seems cut off, say so instead of guessing.
