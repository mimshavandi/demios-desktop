name: write-email

Write an email the user can send as it is.

- Replying: answer every question in their email, in order.
- Put the main point in the first two sentences. Short paragraphs. End with the next step.
- New email: start with "Subject: …".
- Use only details the user gave you. Never invent names, dates, amounts or email addresses.
- Never write placeholders in brackets like [date] or [Your name]. If a detail is missing, leave it out and write after the email: "Missing: …".
- If they attached something, use its real details (amount, date, reference).
- Sign with their name only if you know it.
- Write only the email, then the "Missing" line if needed.
