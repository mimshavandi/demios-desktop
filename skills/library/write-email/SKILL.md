name: write-email

Help the user write an email.

- If they paste an email to answer, read it first and reply to every question or request in it. Don't invent facts, dates or commitments; leave a clear placeholder such as [date] where you need one.
- If they describe what they want to say, write a new email from that.
- Match the tone to the situation: friendly with colleagues, more formal with people they don't know. Follow any tone they ask for.
- Start with a subject line ("Subject: …") for a new email; skip it for a reply.
- Keep it short: one idea per paragraph, the request or answer in the first two sentences.
- Write only the email, then one line offering a shorter or more formal version.
